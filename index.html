Linear Regression with Two Independent Variables and Polynomial Terms

Let $x_1$ and $x_2$ be two independent variables. A combined polynomial model (up to third-order for each predictor) can be written as:

$$y_i = \beta_0 + \sum_{j=1}^{d_1} \beta_j \, x_{1i}^{\,j} + \sum_{k=1}^{d_2} \gamma_k \, x_{2i}^{\,k} + \varepsilon_i$$
where $d_1, d_2 \in \{1,2,3\}$ (first-/second-/third-order), and $\varepsilon_i$ is the random error term.

Sum of Squared Errors (SSE)

For simple linear regression

$$\hat{y}_i = a + b x_i$$
the Sum of Squared Errors is:

$$\mathrm{SSE}(a,b) = \sum_{i=1}^{n} \left(\hat{y}_i - y_i\right)^2 = \sum_{i=1}^{n} \left(a + b x_i - y_i\right)^2$$

Gradient Descent update (slope)

Holding $a$ fixed, gradient descent updates $b$ by:

$$b^{(t+1)} = b^{(t)} - \eta \, \frac{\partial \mathrm{SSE}(a,b)}{\partial b}$$
where $\eta$ is the learning rate.

This interactive app demonstrates how logistic regression and a linear probability model (LPM) behave when the dependent variable is binary. In this example, the outcome is whether a customer clicked an advertisement (1 = clicked, 0 = not clicked) based on ad spend.

Logistic Regression

Logistic regression models the probability that the outcome equals 1:

$$ P(\text{Clicked}=1 \mid X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}} $$

Linear Probability Model

The linear probability model applies ordinary least squares regression to a binary dependent variable:

$$ \hat{Y} = \beta_0 + \beta_1 X $$

ANN Visualization

This notebook provides an interactive visualization of a small neural network to illustrate how inputs are transformed through hidden layers and combined to produce a nonlinear prediction. By adjusting weights and biases manually, it helps build intuition about how neural networks construct flexible “squiggle” curves and map inputs to probability-like outputs.

How the Neural Network Builds the Final Prediction

This GUI illustrates the forward pass of a small neural network. The sliders manually control the weights and biases, allowing a user to see how hidden-node transformations are combined to create a nonlinear prediction curve.

This neural network transforms the input (ad frequency, (x)) through a sequence of steps to produce the final prediction.

Step 1: Linear Transformation at Hidden Nodes

Each hidden node applies a linear transformation:

$$z_1 = W_1 x + b_1$$ $$z_2 = W_2 x + b_2$$

These transformations shift and scale the input differently for each node.

Step 2: Nonlinear Activation (Sigmoid)

The transformed values pass through the sigmoid function:

$$h_1 = \sigma(z_1)$$ $$h_2 = \sigma(z_2)$$

This introduces nonlinearity, allowing the model to capture curved relationships.

Step 3: Scaling by Output Weights

Each hidden node output is scaled:

$$W_3 h_1$$ $$W_4 h_2$$

These weights determine the relative influence of each hidden node.

Step 4: Summation

The scaled outputs are combined:

$$W_3 h_1 + W_4 h_2$$

This aggregates the learned nonlinear patterns.

Step 5: Output Bias Adjustment

A bias term shifts the combined result:

$$W_3 h_1 + W_4 h_2 + b_3$$

This allows flexibility in the overall level of the prediction.

Step 6: Final Sigmoid Output

The final output is obtained using the sigmoid function:

$$\hat{y} = \sigma(W_3 h_1 + W_4 h_2 + b_3)$$

This ensures the prediction lies between 0 and 1.

Interpretation

  • Hidden nodes create nonlinear transformations of the input.
  • The output layer combines these transformations.
  • The final sigmoid produces a probability-like prediction.

This structure allows the model to capture patterns such as:

  • low effectiveness at very low ad frequency,
  • higher effectiveness at moderate levels,
  • and potential decline at very high frequency.
